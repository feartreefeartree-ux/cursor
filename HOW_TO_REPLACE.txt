整份覆盖 linker\FanCanAppTest.sct（不要用带 #! 的版本）

L6226E %TSD-Header- 和 L6228E Expected '{' found '#' 是因为上一份 sct 第一行是
  #! armclang ... -E
Keil 预处理失败（常见于公司 IPGSD/加密把 .sct 包了一层），链接器就把 #if 和加密头当成域名字。

这一份没有任何 # 和 #!，armlink 直接读。

1. 退出 Keil。
2. 旧文件改名 FanCanAppTest.sct.bak。
3. 用新的 FanCanAppTest.sct 覆盖到工程 linker\ 目录。
   用 VS Code / 记事本另存为 ANSI 或 UTF-8 无 BOM。不要 Unicode。
   不要用微信/邮件直接保存；可先存成 .txt 再改名为 .sct。
4. Options → Linker 确认 Scatter File 仍是 .\linker\FanCanAppTest.sct，未勾选 Use Memory Layout from Target Dialog。
5. Rebuild。

邮箱在 0x20000000 长度 0x80。若要和 ECU 一致，只改 RW_BOOT_APP_MAILBOX 那一行的地址和长度。
